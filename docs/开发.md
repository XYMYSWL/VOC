## 编译

需要 Rust（MSVC 工具链）+ Visual Studio 生成工具（含「使用 C++ 的桌面开发」）：

```powershell
cargo +stable-x86_64-pc-windows-msvc build --release
```

或者直接运行 `.\build.ps1`：Windows 客户端 / 服务端、MSIX 安装包、单文件安装程序 `VOC-Setup.exe`（首次会自动生成自签名证书，私钥存在
`%USERPROFILE%\.voc-signing\`，不在仓库里）、Linux 服务端安装包全部输出到 `dist\`。

> 注：Windows 有 260 字符路径限制（libopus 的 MSBuild 尤其敏感）。项目放在很深的目录时，
> 可以在**仓库外层目录**建一个 `.cargo/config.toml`（Cargo 会自动向上合并读取，不会提交进 Git），写本机专用设置：
>
> ```toml
> [build]
> target-dir = "C:/voc-target"          # 短路径
> [env]
> CMAKE = "C:/Program Files (x86)/Microsoft Visual Studio/2022/BuildTools/Common7/IDE/CommonExtensionsMicrosoft/CMake/CMake/bin/cmake.exe"
> NASM = "C:/Program Files/NASM/nasm.exe" # openh264 汇编优化（软件编码快约 10 倍）：winget install NASM.NASM
> ```
>
> 默认的 `windows-gnu` 工具链缺少汇编器，编不过 `windows-sys`，请用 MSVC 工具链。
> 做 MSIX 安装包需要 Windows SDK（自带 `makeappx.exe` / `signtool.exe`）。

## 测试

```powershell
cargo +stable-x86_64-pc-windows-msvc test --workspace
```

包含编解码、重采样、抖动缓冲、降噪、握手/加密/防重放单元测试，以及启动真实服务器进程的端到端测试：
加密语音转发、重放丢弃、UDP 被封时走 TCP、错误授权码与探测得不到任何响应、吊销踢人、同码顶号、
P2P 信令 + 打洞 + 直连语音 + 服务器不给直连对象转发、服务器转发的聊天和语音里不含明文；
端到端加密单元测试：伪造的身份公告 / 成对密钥被拒、身份变化被拦截、离开频道的人解不开新语音、重放被拒；
以及两个真实客户端语音链路在本机互相打洞并直连通话（端到端加密）；屏幕共享：服务器只转给观看者、关键帧请求、停止后不再转发；
视频全流程（编码 → 加密 → 分片 → 乱序 / 丢片 → 重组 → 解密 → 解码，丢片触发关键帧请求）。

界面截图（开发用，不联网，用假数据渲染后自动截图退出）：

```powershell
$env:VOC_DEMO="main"; $env:VOC_SHOT="main.png"; .\dist\voc-client.exe   # VOC_DEMO 可选 login / main / settings / share / viewer
```

需要桌面 / 外网的手动测试：

```powershell
# 真实屏幕采集 → 1080p60 → 两个客户端 P2P → 解码，打印帧率
$env:VOC_LIVE_HEIGHT=1080; $env:VOC_LIVE_SECS=3; cargo +stable-x86_64-pc-windows-msvc test --release -p voc-client live_screen_share -- --ignored --nocapture
# 连真实服务器：登录 + UDP 是否可达
$env:VOC_REMOTE="服务器IP"; $env:VOC_CODE="授权码"; cargo +stable-x86_64-pc-windows-msvc test -p voc-server --test e2e remote_smoke -- --ignored --nocapture
```

## 降噪：RNNoise 与 Krisp

设置 → 「AI 降噪」三选一：

- **关闭**
- **RNNoise（内置，免费，默认）**：开源神经网络降噪，对风扇、空调、键盘这类背景噪音效果好；
  对很"嘶"的白噪音削减有限。
- **Krisp / 外部插件**：从 DLL 加载第三方降噪。

### 接入 Krisp

Krisp SDK 不公开下载，需要先向 Krisp 申请开发者账号和商业授权。拿到 SDK 后：

1. 打开 `plugins/krisp_shim/krisp_shim.cpp`，按你那个 SDK 版本的头文件和示例，把标了 `TODO(krisp)` 的
   4 处（全局初始化、加载模型并创建 48 kHz / 10 ms 会话、处理一帧、释放）换成真实调用。
2. 编译出 `voc_krisp.dll`（`plugins/krisp_shim/CMakeLists.txt`，或直接用 MSVC：
   `cl /LD /EHsc /std:c++17 /utf-8 krisp_shim.cpp <Krisp 的 .lib> /Fe:voc_krisp.dll`）。
3. 把 `voc_krisp.dll` 和 Krisp SDK 自带的 DLL 放同一个目录。
4. 客户端设置里选「Krisp / 外部插件」，填 DLL 路径和模型文件路径，点「加载插件」。

插件出错时客户端会自动停用插件、透传原声，不会把你的麦克风弄没声。
插件接口见 `plugins/voc_denoise.h`，任何降噪库都可以照着接进来。

## 自动构建

- `.github/workflows/ci.yml`：每次推送到 main 或开 PR，在 Windows 上编译并跑全部测试，在 Linux 上测试服务端并静态编译 x86_64 / arm64。
- `.github/workflows/release.yml`：推送版本标签（例如 `v0.4.0`，要和 Cargo.toml 的版本一致）时自动打包并发布 Release。
  MSIX 和 VOC-Setup.exe 需要签名私钥，存在仓库 Secrets 里：`VOC_PFX_BASE64`（VOC.pfx 的 base64）和 `VOC_PFX_PASSWORD`；
  没配置时只发布不需要签名的文件（`build.ps1 -NoSign`）。

## 测试用的环境变量

| 变量 | 作用 |
| --- | --- |
| `VOC_DEMO=main / login / settings / share / viewer / fullscreen` + `VOC_SHOT=文件.png` | 用假数据渲染界面并截图（不联网） |
| `VOC_AUTOLOGIN="地址\|昵称\|授权码\|频道ID"` | 启动后自动登录并进频道，不读写保存的配置（测重连等） |
| `VOC_TEST_SEND_IMAGE=图片路径` | 配合 VOC_AUTOLOGIN：进频道后自动发这张图 |
| `VOC_LIVE_HEIGHT` / `VOC_LIVE_SECS` / `VOC_LIVE_ENCODER` | `live_screen_share_over_p2p`（真实屏幕采集 → 编码 → P2P → 解码）的分辨率、至少跑几秒、编码器 |
| `VOC_LIVE_LOW=1`（+ `VOC_LIVE_ONLY_LOW=1` / `VOC_LIVE_99_CAPS=1`） | 同一个测试：同时编原画和 360P 低画质层 |
| `VOC_NO_GPU_PIPE=1` | 不走显卡直通，强制 CPU 转换 |
| `VOC_TEST_SHARE=720 / 1080` | 配合 VOC_AUTOLOGIN：进频道后自动共享屏幕 |
| `VOC_TEST_WATCH=main / low` + `VOC_TEST_VIDEO_ROUTE=p2p / server` | 配合 VOC_AUTOLOGIN：自动看第一个在共享的人（画质、画面线路） |
| `VOC_TEST_LOG=文件` | 每秒追加一行共享 / 观看状态（编码帧率、码率、解码帧率、画面线路） |
| `VOC_TEST_NO_P2P=1` | 配合 VOC_AUTOLOGIN：关掉 P2P |
| `VOC_TEST_LOSS=百分比` | 随机丢掉收到的画面包，模拟网络丢包（看补发 / 冗余的效果） |
| `VOC_TEST_FPS` / `VOC_TEST_QUALITY=0/1/2` / `VOC_TEST_RTX=0` | 配合 VOC_TEST_SHARE：帧率、画质档位；`RTX=0` 模拟不支持补发的旧版共享者 |
| `VOC_NO_INTRA_REFRESH=1` | 不开逐行刷新 |
| `VOC_NO_GPU_PIPE=1` | 屏幕共享不用显卡直通（对比测试） |
| `VOC_LIVE_HEIGHT` / `VOC_LIVE_SECS` / `VOC_LIVE_ENCODER` | `live_screen_share_over_p2p` 真机测试的参数 |

需要真机（声卡、显卡、Windows 11）的测试默认不跑，用 `-- --ignored` 运行：
`real_device_buffers`（声卡 10 ms 缓冲）、`loopback_real_capture`（按程序录音）、`music_from_real_program`（伴奏全链路）、
`live_screen_share_over_p2p`（真实屏幕共享）、`hw_encode_decode_all_codecs`（所有硬件编解码器）、`desktop_shortcut`（需要已安装 VOC）。
