VOC 语音 —— 客户端使用说明
==========================

运行环境：Windows 10 1903 及以上 / Windows 11（64 位）。伴奏和共享电脑声音需要 Windows 11。

安装（二选一）
  A. 安装版（推荐）：双击 VOC-Setup.exe，装好会自动打开。以后从开始菜单打开 VOC。
     第一次安装会弹一次「是否允许更改」，点「是」（用来信任 VOC 的签名证书，以后升级不会再弹）。
     安装时可以勾选「创建桌面快捷方式」（默认勾上）。
     如果出现「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
     有新版本时，点顶栏的「⬆ 新版本」即可一键更新。
     卸载：开始菜单右键 VOC → 卸载。
  B. 绿色版：解压 VOC-portable.zip，双击 VOC.exe（有新版需要手动下载）。
     如果出现「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」（程序没有购买代码签名证书，不是病毒）。
     如果 Windows 防火墙询问是否允许 VOC 访问网络：请允许（P2P 直连需要）。

登录
  服务器：填管理员给你的服务器地址（IP 或域名，默认端口 7878 不用写）
  昵称：随便起
  授权码：填管理员给你的 KH-XXXXXXXX-… 授权码
  可以点「💾 保存」把这个服务器存进「我的服务器」，下次一点就能进。

第一次进来建议先调麦克风
  点「⚙ 设置」→ 音频：
  - 选好麦克风和扬声器
  - 说话方式：
      语音激活：看电平条，说话时要超过白线、不说话时低于白线，不合适就拖动「灵敏度阈值」
      按键说话：按住设定的键才说话（键盘键、鼠标中键或侧键都行，游戏里也有效），松开后多发 0.2 秒
  - 回声消除：不戴耳机、用扬声器外放时开着（默认开），队友就不会听到自己的回声
  - 勾「麦克风测试」可以听到自己的声音（建议戴耳机）
  - 「进出提示音」：有人进出频道时「噔、噔」两声，可调音量、试听或关闭
  AI 降噪默认开启（RNNoise），在「降噪」页调整。
  耳机、麦克风拔插或换了系统默认设备，VOC 会自动切过去，聊天里会提示。

使用
  点左边的语音频道就能进去说话，说话时头像有绿圈。
  Ctrl+M 闭麦，Ctrl+D 静音（左下角也有按钮）。右键队友可单独调音量、看直连质量和安全码。
  名字旁边的图标：
    🔒  端到端加密已建立（服务器听不到你们说话、看不到聊天）
    ⇄ 23 ms  P2P 直连及延迟（不经过服务器）
    ⇄ 打洞中 3s / 打不通·走服务器 / 对方未开直连 / 对方 UDP 不通：和这个人的直连状态
    🎵 程序名  这个人正在放伴奏
    ⚠   对方的加密身份变了，已暂停加密通信 —— 和对方核对安全码后右键「信任」
  右键名字还能看「听他说话的延迟」（估算的嘴到耳延迟）。
  顶栏「🔒 UDP 直连」正常；「🔒 TCP 隧道」表示 UDP 被封或不稳，已自动改走 TCP，延迟会高一些。
  「我能听到他、他听不到我」或某个人声音断断续续：右键他的名字 →「和他之间的线路」，
    选「走服务器」（不直连、不经队友中转）或「强制 P2P 直连」（打通了就一直直连，打不通仍走服务器）；默认「自动」。
  麦克风一直完全没声音时聊天框上方会提示：多半是 Windows 设置 → 隐私和安全性 → 麦克风 里没允许桌面应用使用麦克风。
  觉得卡、和队友连不上：设置 → 网络 → 网络自检，会告诉你 UDP 通不通、延迟丢包多少、路由器有没有开端口映射，并给出建议。
  用手机热点或网络很差：设置 → 网络 → 打开「低带宽模式」（语音码率减半，屏幕共享最高 480P）。
  网络断了会自动重连，连上后回到原来的语音频道，聊天记录还在。

发图片
  聊天框左边的 🖼 选图，或者 Ctrl+V 粘贴截图、直接把图片拖进窗口。
  只发给同一个语音频道里的人，最大 20 MB（更大的会自动压缩），端到端加密，服务器只转发不保存。
  点缩略图看大图。

私聊
  右键对方名字 →「💬 私聊」，聊天区上方出现和他的对话标签，有新消息会显示数字。
  文字和图片都只发给对方，端到端加密；对方在别的频道也能收到。点标签上的 ✕ 关闭并清除这段对话。

阅后即焚
  聊天、私聊和图片只在内存里，不存到电脑上，也不能另存图片。断开、重连时还在；关掉 VOC 就全部清除。
  （对方仍然可以截屏或拍照。）

伴奏
  进入语音频道后，左下角点 🎵，选一个正在出声的程序（音乐播放器等），它的声音就会放给频道里的人。
  不经过麦克风，闭麦也照放。「我这边听到的音量」只影响你自己听到的大小，别人听到的不变。
  别人可以右键你的名字单独调你的伴奏音量。需要 Windows 11。

托盘与开机自启
  点右上角 ✕ 会缩到右下角托盘，语音不断；点托盘图标打开窗口，右键可以闭麦、静音或退出。
  设置 → 关于：可以关掉「关闭窗口时缩到托盘」，或打开「开机自动启动」（自动登录上次的服务器、回到上次的频道，需要记住授权码）。

屏幕共享
  进入语音频道后，左下角点「🖥 共享屏幕」：选显示器、分辨率（480P / 720P / 1080P）、帧率（30 / 60）和编码器，点「开始共享」。
  勾上「同时共享电脑声音」，游戏、视频的声音会一起发给正在看的人（不含队友的说话声和 VOC 的提示音，需要 Windows 11）。
  别人名字旁出现「📺 观看 1080p60」按钮，点一下就会弹出画面窗口，窗口可以拉大缩小。
  双击画面或点「全屏」全屏观看，Esc 退出；观看窗口里可以单独调共享声音的音量。
  观看窗口上方可以选「原画」或「流畅」（360P，省流量、网络差时更不容易卡）。
  没人看时不编码、不占流量；能 P2P 直连的观看者不经过服务器；画面也是端到端加密的。
  显卡和显示器是同一块时，画面全程在显卡上处理（共享窗口显示「显卡直通」），打游戏时不抢 CPU。
  网络拥堵时画面码率会自动降低（共享窗口里会提示），好转后自动恢复。

编码器 / 解码器（设置 → 视频）
  编码器选「自动」即可：有显卡编码器就用显卡，并在所有观看者都能解的格式里挑最省流量的
  （AV1 最省，约为 H.264 的 6 成流量；其次 HEVC；最后 H.264）。
  也可以手动选用哪块显卡（NVIDIA / AMD / Intel）编码，或选「软件编码」（用 CPU）。
  解码可选「硬解」（显卡，省 CPU，默认）或「软解」（CPU，显卡驱动有问题时用）。
  共享窗口 / 观看窗口里会显示实际用的编码器和解码器。
  大约占用上行带宽（H.264；HEVC 约 ×0.75，AV1 约 ×0.6）：480P 0.9~1.4 Mbps，720P 2~3 Mbps，1080P 3.5~5.5 Mbps
  （每位观看者一份，直连时由你的上行承担）。

隐私与带宽
  设置 → 网络 页 →「P2P 直连语音」：开启时同频道的人能看到你的 IP；不想暴露就关掉（只走服务器）。
  设置 → 网络 页 →「直连上行预算」：直连要给每个人各发一份，超出预算的人自动改走服务器。建议设成你宽带上行的一半左右（默认 15 Mbps）。
  名字下方「⇄ 23 ms」：绿/黄/红 = 正在直连（颜色表示延迟）；灰色「中转」= 已打通但超出预算；
  黄色「不稳·中转」= 直连丢包或抖动太大，已自动改走服务器，稳定后会自动切回。右键名字可看丢包和抖动。
  「↪ 经 某人 62 ms」= 你们俩打不通直连，由这位队友帮忙转发，62 ms 是往返延迟。
     鼠标悬停或右键名字可以看线路对比：经队友 / 经服务器（慢多少）/ 直连为什么不能用。仍然端到端加密。
  「🔁 帮 A ↔ B 中转」（在你自己名字下）= 你的网络好，正在帮他们转发语音；不想帮忙可在 设置 → 网络 关掉「帮队友中转语音」。
  每个语音频道最多 20 人，频道名后面显示当前人数。
  设置 → 加密 →「我的安全码」：别人核对你身份时，把这串数字念给他。

检查更新
  启动时会自动检查有没有新版本（只匿名访问 GitHub，不上传任何信息），有新版时顶栏会出现「⬆ 新版本」按钮，安装版点一下就会自动下载安装并重新打开。
  设置 → 关于：手动检查更新，或关闭自动检查；「复制诊断信息」可以把网络、声卡、显卡信息复制下来发给帮你排查问题的人（不含聊天和密钥）。
  开源地址：https://github.com/XYMYSWL/VOC
