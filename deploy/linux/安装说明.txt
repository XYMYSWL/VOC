VOC 服务器 —— Linux 安装说明
================================

支持：64 位 Linux（x86_64 / arm64），需要 systemd。
      Ubuntu 18.04+、Debian 10+、CentOS/Rocky/Alma 8+、openSUSE 等都可以。
程序是静态编译的，不依赖系统里的任何库。

最简单：服务器能访问 GitHub 的话，登录服务器后执行一行命令即可（装过就是升级）：

    curl -fsSL https://github.com/XYMYSWL/VOC/releases/latest/download/get.sh | sudo bash

服务器访问不了 GitHub 时，按下面的步骤离线安装：

一、上传到服务器（在你自己的 Windows 电脑上，PowerShell 里执行）

    scp voc-server-linux.tar.gz root@你的服务器IP:/root/

二、登录服务器安装

    ssh root@你的服务器IP
    tar xzf voc-server-linux.tar.gz
    cd voc-server-linux
    sudo bash install.sh --name "我的 VOC 服"

    可选参数：
      --port 443                     换端口（443 更像普通 HTTPS 流量，抗封锁更好）
      --channels "大厅,五排,双排"     初始语音频道
      --bind-ip ::                   同时监听 IPv6
      --no-firewall                  不自动改本机防火墙

    安装完成后会显示第一个授权码（只显示一次），用它在客户端登录。

三、云服务器一定要放行端口

    在云服务商控制台（阿里云 / 腾讯云 / 华为云 / AWS / Oracle 等）的「安全组」或「防火墙」里，
    放行 TCP 和 UDP 的 7878 端口（或你用 --port 指定的端口）。只放行 TCP 的话语音会走 TCP 隧道，延迟会高一些。

四、日常管理（在服务器上）

    sudo voc gen-code --note 小明          给小明生成授权码
    sudo voc gen-code -n 5 --days 30       生成 5 个 30 天有效的授权码
    sudo voc list-codes                    查看所有授权码
    sudo voc revoke-code <ID>              吊销（在线的人会被踢下线）
    sudo voc restore-code <ID>             恢复
    sudo voc export-users > 授权码备份.txt  换服务器时导出全部授权码（会让你设一个密码，内容加密）
    sudo voc import-users 授权码备份.txt    在新服务器上导入（输同一个密码），大家原来的授权码照样能用
    sudo voc status                        查看运行状态
    sudo voc logs                          实时查看日志（Ctrl+C 退出）
    sudo voc restart                       重启
    sudo voc config                        修改名称 / 端口 / 频道，保存后自动重启

五、升级

    sudo voc upgrade                  一键升级到最新版（需要能访问 GitHub）
    sudo voc version                  查看当前版本

    离线升级：上传新的 voc-server-linux.tar.gz，解压后运行 sudo bash install.sh --upgrade
    授权码和配置都会保留。

六、卸载

    sudo bash uninstall.sh            保留授权码和配置
    sudo bash uninstall.sh --purge    全部删除

文件位置
    程序          /usr/local/bin/voc-server
    管理命令      /usr/local/bin/voc
    配置          /etc/voc/voc.conf
    授权码        /var/lib/voc/voc-codes.json   （请勿外泄：拿到它就能冒充用户登录）
    服务          voc-server（systemd，开机自启，崩溃自动重启）

注意
    服务器时间要准（与客户端相差不能超过 10 分钟），安装脚本会自动开启 NTP 时间同步。
    服务器只转发加密数据：语音和聊天是端到端加密的，服务器本身听不到也看不到内容。
