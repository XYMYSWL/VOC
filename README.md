# VOC

**自己搭的加密语音开黑软件**，类似 Discord / Oopz 的语音频道，但服务器是你自己的，而且听不到你们说话。

[**⬇ 下载 Windows 版**](https://github.com/XYMYSWL/VOC/releases/latest) · [服务端部署](docs/服务端部署.md) · [技术细节](docs/技术细节.md) · [开发](docs/开发.md)

## 亮点

- 🔒 **端到端加密**：语音、聊天、屏幕共享，服务器只转发密文（抗量子算法 ML-KEM-768 / ML-DSA-65）
- ⚡ **低延迟**：能直连就 P2P 直连，不稳或打不通时自动改走服务器中转
- 🖥 **屏幕共享**：最高 1080P 60 帧，自动用显卡编码，挑最省流量的格式（AV1 / HEVC / H.264）
- 🎙 **AI 降噪**：内置 RNNoise，默认开启
- 🛡 **抗封锁**：流量看起来是随机字节，探测得不到响应；UDP 被封时自动切到 TCP
- 🔑 **授权码登录**：只有拿到授权码的人能进，随时可以吊销
- ⬆ **一键安装、一键更新**

## 快速开始

### 1. 搭服务器（管理员做一次）

找一台有公网 IP 的 Linux 服务器，下载 Release 里的 `voc-server-linux.tar.gz`：

```bash
tar xzf voc-server-linux.tar.gz && cd voc-server-linux
sudo bash install.sh --name "我的 VOC 服"
```

装完会打印第一个授权码。给朋友生成授权码：

```bash
sudo voc gen-code --note 小明
```

> 云服务器记得在控制台「安全组」放行 **TCP 和 UDP 7878**。Windows 服务端、换端口、升级卸载见 [服务端部署](docs/服务端部署.md)。

### 2. 装客户端（每个人）

下载 [**`VOC-Setup.exe`**](https://github.com/XYMYSWL/VOC/releases/latest)，双击，装好自动打开。

- 第一次会问「是否允许更改」，点 **是**（用来信任 VOC 的签名证书，只问这一次）。
- 如果提示「Windows 已保护你的电脑」：点 **更多信息 → 仍要运行**。
- 不想安装？下载 `VOC-portable.zip`，解压直接运行。

### 3. 进频道

填 **服务器地址**、**昵称**、**授权码** → 登录 → 点左边的语音频道就能说话。

第一次用建议点 **⚙ 设置** 调一下麦克风灵敏度：说话时电平超过白线、不说话时低于白线。

## 常用操作

| 想做什么 | 怎么做 |
| --- | --- |
| 闭麦 / 静音 | `Ctrl+M` / `Ctrl+D`，或左下角按钮 |
| 单独调某人音量 | 右键他的名字 |
| 共享屏幕 | 左下角 **🖥 共享屏幕**，选分辨率和帧率 |
| 看别人共享 | 点他名字旁的 **📺 观看** |
| 选显卡 / 硬解软解 | 设置 → 视频 |
| 不想暴露 IP | 设置 → 网络 → 关掉「P2P 直连」 |
| 更新 | 顶栏出现 **⬆ 新版本** 时点它 |

名字旁的图标：**🔒** 加密已建立 · **⇄ 23 ms** 直连及延迟 · **⚠** 对方身份变了，核对安全码前暂停加密通信。

## 要求

- 客户端：Windows 10 1903 及以上（64 位）
- 服务端：64 位 Linux（x86_64 / arm64，带 systemd），或 Windows
