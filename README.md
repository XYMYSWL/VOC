# VOC

**自己搭的加密语音开黑软件**，类似 Discord / Oopz 的语音频道，但服务器是你自己的，而且听不到你们说话。

[**⬇ 下载 Windows 版**](https://github.com/XYMYSWL/VOC/releases/latest) · [服务端部署](docs/服务端部署.md) · [技术细节](docs/技术细节.md) · [开发](docs/开发.md)

## 亮点

- 🔒 **端到端加密**：语音、聊天、图片、屏幕共享、伴奏，服务器只转发密文（抗量子算法 ML-KEM-768 / ML-DSA-65）
- 🔥 **阅后即焚**：聊天、私聊和图片只在内存里，关掉 VOC 就清零销毁，服务器和电脑上都不留
- ⚡ **低延迟**：自适应抖动缓冲、10 ms 声卡缓冲；能直连就 P2P 直连，打不通时由延迟最低的队友帮忙转发，最后才走服务器；断线自动重连
- 🖥 **屏幕共享**：最高 1080P 60 帧、画质可选到约 25 Mbps，画面全程在显卡上处理（打游戏不抢 CPU）；丢包时自动补发、加冗余校验包，网络有点丢包也不卡；可带电脑声音，可全屏看；观看的人可以选「流畅」省流量
- 🎵 **伴奏**：把某个程序（音乐播放器等）的声音放给频道里的人，每个人单独调音量
- 🎙 **声音处理**：AI 降噪（RNNoise）、回声消除（外放也能用）、语音激活或按键说话
- 🛡 **抗封锁**：流量看起来是随机字节，探测得不到响应；UDP 被封时自动切到 TCP
- 📶 **网络差也能用**：低带宽模式（手机热点也能聊）；网络自检告诉你卡在哪、怎么改
- 🔑 **授权码登录**：只有拿到授权码的人能进，随时可以吊销
- ⬆ **一键安装、一键更新**

## 快速开始

### 1. 搭服务器（管理员做一次）

找一台有公网 IP 的 Linux 服务器，执行一行命令：

```bash
curl -fsSL https://github.com/XYMYSWL/VOC/releases/latest/download/get.sh | sudo bash
```

装完会打印第一个授权码。以后的常用命令：

```bash
sudo voc gen-code --note 小明    # 给朋友生成授权码
sudo voc upgrade                 # 升级到最新版（授权码和配置都保留）
```

> 云服务器记得在控制台「安全组」放行 **TCP 和 UDP 7878**，以及 **UDP 7879**（NAT 探测，可选：放行后能准确判断 NAT 类型、提高直连成功率）。Windows 服务端、换端口、离线安装、卸载见 [服务端部署](docs/服务端部署.md)。

### 2. 装客户端（每个人）

下载 [**`VOC-Setup.exe`**](https://github.com/XYMYSWL/VOC/releases/latest)，双击，装好自动打开。

- 第一次会问「是否允许更改」，点 **是**（用来信任 VOC 的签名证书，只问这一次）。
- 如果提示「Windows 已保护你的电脑」：点 **更多信息 → 仍要运行**。
- 不想安装？下载 `VOC-portable.zip`，解压直接运行。

### 3. 进频道

填 **服务器地址**、**昵称**、**授权码** → 登录 → 点左边的语音频道就能说话。

第一次用建议点 **⚙ 设置** 调一下麦克风灵敏度：说话时电平超过白线、不说话时低于白线。

## 常用操作

| 想做什么 | 怎么做 |
| --- | --- |
| 闭麦 / 静音 | `Ctrl+M` / `Ctrl+D`（全局快捷键，游戏里也有效，按下会响一声），或左下角按钮；设置 → 音频 → 快捷键 可以换成别的键 |
| 单独调某人音量 | 右键他的名字 |
| 共享屏幕 | 左下角 **🖥 共享屏幕**，选分辨率、帧率和画质（标准 / 高 / 极高），可勾选「同时共享电脑声音」 |
| 看别人共享 | 点他名字旁的 **📺 观看**；双击画面全屏，Esc 退出 |
| 放伴奏 | 左下角 **🎵**，选一个正在出声的程序 |
| 发图片 | 聊天框左边 **🖼**，或 Ctrl+V 粘贴截图、直接拖进窗口（只发给同频道的人，最大 20 MB） |
| 私聊 | 右键对方名字 → **💬 私聊**，聊天区上方出现对话标签；点标签上的 ✕ 关闭并清除 |
| @某人 | 聊天框里打 `@`，点出现的名字；对方不在 VOC 窗口时会收到 Windows 通知 |
| 表情回应 | 右键一条消息，点表情；再点一次取消 |
| 看共享时省流量 | 观看窗口上方点 **流畅**（360P），点 **原画** 换回来 |
| 网络卡 / 流量少 | 设置 → 网络 → **低带宽模式** |
| 查网络问题 | 设置 → 网络 → **网络自检**（UDP 通不通、延迟丢包、NAT 类型、路由器端口映射，附建议） |
| 按键说话 | 设置 → 音频 → 说话方式 → 按键说话（键盘键或鼠标侧键，游戏里也有效） |
| 选显卡 / 硬解软解 | 设置 → 视频 |
| 不想暴露 IP | 设置 → 网络 → 关掉「P2P 直连」；或右键某人选「走服务器」，只对他隐藏 |
| 关窗口不断语音 | 点 ✕ 会缩到右下角托盘；右键托盘图标可闭麦、静音、退出 |
| 开机自启 | 设置 → 关于 → 开机自动启动（自动登录并回到上次的频道） |
| 更新 | 顶栏出现 **⬆ 新版本** 时点它；在中国大陆下载慢、连不上 GitHub：设置 → 关于 → 勾「中国大陆加速更新」 |

名字下的状态：**⇄ 23 ms** 已直连 · **⇄ 打洞中 3s** / **打不通·走服务器** / **对方 UDP 不通** 等打洞状态 · **↪ 经 某人 62 ms** 由这位队友中转（悬停对比服务器线路） · **🔁 帮 A ↔ B 中转** 你在帮队友中转 · **🎵 程序名** 正在放伴奏。右键名字可以看「听他说话的延迟」。

## 要求

- 客户端：Windows 10 1903 及以上（64 位）；伴奏和共享电脑声音需要 Windows 11
- 服务端：64 位 Linux（x86_64 / arm64，带 systemd），或 Windows
